#### Vấn đề 5 — PLAXIS JSON serializer

**File engine:** [scripts/plaxis_serializer.py](scripts/plaxis_serializer.py)
**Bảng SQLite mới:** `cdm_plaxis_model_recipes` (zone_code PK, recipe_json, n_bh, n_layers, n_materials, source_db, created_at)
**Files JSON snapshot:** `plaxis_out/recipe_*.json` (5 zone × 1 file/zone)

**Cấu trúc recipe:**
```json
{
  "zone_code": "KE_levee",
  "design_elev_fill_m": 2.7,
  "source_db": "...",
  "created_at": "2026-05-29 16:xx:xx",
  "n_boreholes": 5,
  "n_global_layers": 11,
  "n_materials": 11,
  "boreholes": [{name, nat_elev_m, E, N, head_m, layer_bottoms_m: {symbol: y}}],
  "global_layers": ["__FILL__", "F", "1", "1b", ...],
  "materials": {symbol: {model, gamma_kNm3, Cu_kPa, phi_deg, ...}}
}
```

**API:**
```python
from plaxis_serializer import (
    build_plaxis_model_recipe,
    save_recipe_to_json, save_recipe_to_sqlite,
    load_recipe_from_json, load_recipe_from_sqlite,
)

# Build từ SQLite
recipe = build_plaxis_model_recipe("KE_levee")

# Serialize
save_recipe_to_json(recipe, Path("plaxis_out/recipe_KE_levee.json"))
save_recipe_to_sqlite(recipe, db_path)

# Re-create trên máy khác
recipe = load_recipe_from_json(Path("recipe_KE_levee.json"))
# → push lên PLAXIS qua plaxis_push_zone_v2.py với recipe input
```

**Đã serialize 5 zones (10 files = 5 JSON + 5 bản trong SQLite):**

| Zone | n_HK | n_layers | n_materials | JSON size |
|---|:---:|:---:|:---:|:---:|
| KE_levee | 5 | 11 | 11 | 5.4 KB |
| QTT | 6 | 6 | 6 | 4.1 KB |
| NHC | 7 | 13 | 13 | 7.0 KB |
| BXN | 9 | 12 | 12 | 7.7 KB |
| KE_park | 5 | 11 | 11 | 5.4 KB |

**Giá trị:** Knowledge persistence — input PLAXIS không còn bị "stuck" trên 1 máy. Recipe có thể commit vào git → reproducible.
